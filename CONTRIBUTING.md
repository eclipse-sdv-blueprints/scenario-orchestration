# Contributing to scenario-orchestration

Thanks for your interest in this Eclipse SDV Blueprint! This project is part of
[Eclipse SDV Blueprints](https://github.com/eclipse-sdv-blueprints) and follows
the [Eclipse Foundation Development Process](https://www.eclipse.org/projects/dev_process).

## Eclipse Contributor Agreement

Before your contribution can be accepted you must:

1. Create an [Eclipse Foundation account](https://accounts.eclipse.org/user/register)
   and link your GitHub username.
2. Sign the [Eclipse Contributor Agreement (ECA)](https://www.eclipse.org/legal/ECA.php).
3. Use the **same email address** for your commits (`git config user.email`) as
   the one registered with your Eclipse account. The ECA check on the pull
   request fails otherwise.

## How to contribute

1. Open an issue to discuss larger changes.
2. Fork the repository and create a topic branch from `main`.
3. Make your changes. Keep commits focused and add a `Signed-off-by` line if possible.
4. Open a pull request against `main` and describe what changed and why.
5. Address review feedback by pushing further commits to the same pull request.
