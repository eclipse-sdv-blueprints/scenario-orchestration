# scenario-orchestration
Orchestrates whole vehicle scenarios across multiple nodes with Pullpiri, Timpani and Kuksa, driven by VSS signals. A hardware demo shows time-triggered workloads keeping deterministic timing under CPU load where conventional workloads drift.

## Contents

- [resource-isolation](./resource-isolation) - demo showing time-triggered (Timpani) vs. conventional workloads under CPU load, in single-node and multi-node setups. See its [README](./resource-isolation/README.md) to get started.
